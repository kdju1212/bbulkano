💡 이 툴은 왜 만들어졌는가?

네이버 검색광고의 소재는 단일형과 반응형으로 구분됩니다. 네이버 광고 정보 일괄 다운로드에서 소재 관련 TSV 파일을 받을 수 있으나, 해당 파일은 가독성이 낮아 소재별 현황을 한눈에 파악하기 어렵습니다.

이 툴은 파편화된 TSV 파일들을 한 번에 업로드 하여 결합하고, 성과 보고서 CSV를 소재 ID 기준으로 연결해 광고제목·설명문구별 효율을 직관적으로 비교할 수 있도록 설계되었습니다.

상단의 단일형·반응형 버튼, 캠페인·광고그룹·소재 단위의 ON/OFF 필터, 랜딩페이지 URL 간소화 표시, 성과 지표(노출·클릭·비용·전환·ROAS 등) 매핑을 통해 소재 효율 분석부터 대량관리용 CSV 추출까지 하나의 흐름으로 처리할 수 있습니다.

핵심 사용 프로세스

1

TSV 파일 업로드 (자동 분류 지원)

네이버 광고 정보 일괄 다운로드에서 캠페인, 광고그룹, 소재(단일/반응), 애셋 등 필요 TSV를 다운로드 후 업로드 합니다.

2

결합 리스트 확인 및 CSV 다운로드

내부 파싱 엔진이 파일 내부 컬럼 구조를 판별하여 소재 구조를 매핑 후 결합된 원본 소재 베이스 CSV 파일을 생성합니다.

3

성과 CSV 업로드 (선택 사항)

네이버 대용량 다운로드 보고서에서 다운로드한 성과 CSV 파일 업로드 시, 소재 ID 기준으로 성과 지표가 매핑됩니다.
헤더 시작 행 설정 기능을 지원하므로, 해당 부분을 조정해주세요. 

4

최종 완성본 다운로드

소재 리스트 혹은 성과 포함 CSV 버튼을 통해 매핑 결과를 다운로드 할 수 있습니다.

준비물 가이드 (네이버 광고 정보 일괄 다운로드)

원활한 데이터 조인을 위해 네이버 광고관리 시스템 내에서 가공되지 않은 순수 원본 형태의 파일들을 다운로드해 주세요.

💡 자동 매핑 알고리즘 핵심 원리

이 시스템은 사용자가 파일을 어떤 칸에 올려야 할지 고민하는 리소스를 제로로 만들기 위해 행 단위 컬럼 스캔 프로토콜을 베이스로 작동합니다.
파일이 인풋되면, 툴 내부 파서가 첫 번째 라인의 탭 공백 기준 토큰 분할을 시도하여 전체 열(Column)의 개수를 체크합니다.
체크된 컬럼 넘버와 헤더 필드의 텍스트 성격(예: 캠페인ID, 광고그룹ID, 소재ID 등 필수 매칭 노드 키값)을 상호 대조하여 각 슬롯 레이어에 데이터를 자동으로 탑재합니다.

🔗 다차원 조인(Join) 프로세스

업로드 완료 후 [소재 리스트 생성] 버튼을 누르면 내부 메모리 데이터베이스 레이어에서 다음과 같은 연산이 일어납니다.

■ 파워링크 단일형 소재 연산

소재 TSV 내부의 광고그룹ID를 조인 키(Join Key)로 삼아 광고그룹 명단과 매칭하여 이름을 뽑아내고, 다시 그 상위의 캠페인ID를 추적해 체인 형태로 결합합니다.

■ 파워링크 반응형 소재 연산

반응형 구조는 텍스트 제목과 설명이 한 파일에 없고 애셋 링크 구조로 분산되어 있습니다. 툴 내부에서 소재 리스트 ↔ 애셋링크 리스트 ↔ 애셋 매스터 3개 테이블을 순차적으로 트리플 조인하여 최종 뷰어 화면에 온전한 텍스트로 치환 복원합니다.
